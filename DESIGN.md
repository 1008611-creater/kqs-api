# Admin Design Memory

## Product And Audience

- Product: 矿泉水 API administrator console.
- Audience: operators making frequent routing, account health, supply, and billing decisions on desktop screens.

## Confirmed Direction

- Treat administration pages as compact operational tools: quiet, information-dense, and professional.
- Prefer continuous work surfaces, dividers, and fixed table columns over marketing panels, gradients, or card stacks.
- Desktop is the active target. Tables must expose their current operational information without horizontal scrolling.
- Keep vertical rhythm aggressively compact on administration pages. Use one continuous control surface with dividers instead of nested or stacked panels with cumulative gaps.
- Keep the desktop administrator sidebar narrow and dense: compact brand area, 32px-class navigation rows, and minimal section gaps.
- Make decision-critical values visually stronger than labels, without turning the page into a dashboard of oversized type.
- Unless explicitly requested, do not place explanatory small text directly below a large heading or large number.
- Page and hero headings stand on their own across user pages and the shared administrator header. Keep supporting copy only where it changes an action, decision, or live-state interpretation.
- Use the existing deep teal/neutral shell with one restrained green-teal action accent; avoid generic AI gradients and decoration.

## User Pages

- Let the mountain-water background remain visible through primary user work surfaces. Use transparent containers with borders, and reserve low-opacity dark fills for controls, sticky headers, hover states, and text-legibility boundaries.
- Apply that transparent-surface treatment consistently across user pages, including the top navigation frame and primary cards; keep modals, inputs, buttons, status chips, table headers, and hover states partially filled for legibility and interaction feedback.
- The user background should carry a misty layered-mountain composition in its upper half and quiet water texture below. Restrained antique-gold lines may accent mountain ridges, cloud edges, and ripples, but must remain a minor detail rather than a bright luxury treatment.
- Primary user surfaces use 60% transparency over the landscape background, implemented as a 40% deep-ink fill; controls may remain more opaque where legibility requires it.
